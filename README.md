One-line joke entry for make.fun One-Liner Laughs: a single original funny line, written by `main.py` to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The program prints the joke to stdout and writes exactly that line to `/output/entry.txt`. Python standard library only, deterministic, no network.
